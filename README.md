# ScientificCalculatorGUI

## Overview
This project implements a fully functional scientific calculator with a graphical user interface (GUI) using Java Swing components. The calculator is designed for both basic and advanced mathematical computations, offering an intuitive and user-friendly interface.

## Features
- **Basic Arithmetic**: Addition, subtraction, multiplication, division.
- **Advanced Functions**:
  - Square root, square, and cube.
  - Trigonometric functions: `sin`, `cos`, `tan`, `asin`, `acos`, `atan`.
  - Hyperbolic functions: `sinh`, `cosh`, `tanh`.
  - Logarithms: Log base 10 (`log`) and natural logarithm (`ln`).
  - Percentage and modulus (`Mod`).
  - Absolute value (`abs`).
- **Interactive GUI**:
  - Buttons for each operation and digit.
  - Real-time display of inputs and outputs.
  - Error handling for invalid inputs or mathematical exceptions (e.g., division by zero).
- **Additional Features**:
  - Clear (`C`) to reset input/output fields.
  - Exit functionality to close the application.

## Technologies
- **Programming Language**: Java
- **Framework**: Java Swing for GUI
